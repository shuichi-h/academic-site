A small utility to parse STARe-exported TGA/STA text files and export merged CSV per sample.

### Features
- Convert Mettler TGA txt data to csv
- Can be used for single curve or multi curves
- Can be used for multi files at once

### Download
[Download TGA_CSV_Exporter.exe]({{site.baseurl}}/scripts/TGA_CSV_Exporter.exe)

### Usage
Drag and drop the raw txt file(s) to this exe icon.
This generate csv file(s) in the same folder.
